Bulk user creation

Prepare hundreds of accounts in a spreadsheet, download the template, fill it, then upload CSV or Excel (.xlsx). Each row is validated independently; invalid rows are reported and not created.

Template columns: username, displayName, role, institutionId, classId, branchId, learnerCategory. Platform Admin can select the institution per row. Institution Admin imports are restricted to their own institution. For every Student row, classId is mandatory and must identify an existing class or learning cohort in that institution.

🛡️

Role assignment

Platform Admin can grant platform and institution roles. Institution Admin can grant non-admin roles only within their institution.

Assigning a Student role also requires selecting an existing class or cohort during account creation. For now, create a new Student account with the correct class rather than adding an unassigned Student role.
